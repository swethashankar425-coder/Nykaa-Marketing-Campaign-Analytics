# Nykaa Marketing Campaign Performance Analytics

## Project Overview

This project analyzes Nykaa's marketing campaign performance from July 2024 to June 2025 using an end-to-end data analytics workflow. The objective was to evaluate campaign effectiveness, customer engagement, conversion performance, audience behavior, and revenue contribution across multiple marketing channels.

The project demonstrates the complete analytics lifecycle from data cleaning and KPI engineering to SQL analysis and interactive dashboard development.

---

## Data Preparation

The dataset was cleaned and transformed using Python by:

* Handling missing values
* Removing duplicates
* Converting date fields to datetime format
* Creating analytical KPIs
* Preparing data for SQL and dashboard reporting

---

## KPI Engineering

The following KPIs were created and analyzed:

* Click Through Rate (CTR)
* Conversion Rate
* Cost Per Click (CPC)
* Cost Per Lead (CPL)
* Acquisition Cost Analysis
* Revenue Analysis
* ROI Analysis

---

## SQL Analysis

Business-focused SQL queries were used to analyze:

* Revenue by Campaign Type
* ROI by Marketing Channel
* Audience Performance
* Campaign Effectiveness
* Conversion Metrics
* Revenue Trends
* Customer Acquisition Performance

---

## Dashboard Features

An interactive Looker Studio dashboard was developed with:

### Executive KPIs

* Total Revenue
* Total Clicks
* Total Leads
* Total Conversions
* Average CTR
* Average ROI
* Average CPL

### Campaign Analysis

* Revenue by Campaign Type
* Leads by Campaign Type
* Campaign Performance Comparison

### Audience Analysis

* Target Audience Revenue Contribution
* Audience Conversion Performance

### Funnel Analysis

A marketing funnel was created to visualize the customer journey:

**Impressions → Clicks → Leads → Conversions**

This helped identify conversion drop-off points and evaluate campaign effectiveness throughout the acquisition process.

## Key Insights

* Identified top-performing marketing channels and campaign types.
* Evaluated customer engagement using CTR and conversion metrics.
* Analyzed audience segments contributing the highest revenue.
* Measured campaign efficiency using ROI, CPC, and CPL.
* Visualized customer journey progression through funnel analysis.
* Built an interactive dashboard for business decision-making.
